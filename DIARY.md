# AI Usage
At the start we gave to the AI an exam assignment, the example project from past lectures, the lecture notes and the task to understand the existing project template to form a CLAUDE.md file.

We added a CHANGELOG.md, DECISIONS.md and QUALITYGOALS.md to keep track of our tasks that we need to fulfill and make AI usage as transparent as possible.

We asked AI to split the tasks in equal parts and in a way that cause as little merge conflicts as possible between the team members. 

# Final Reflection & Lessons Learned
With the PR based workflow it was hard to start with another task, before the first one was not reviewed & merged. This caused a need for rebases of the feature branches and a need for resolving merge conflicts.
